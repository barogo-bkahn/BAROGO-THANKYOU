# 칭찬교환소

동료에게 받은 고마움, 칭찬으로. 동료에게 받은 칭찬, 팀의 간식으로.

## 현재 운영 방식 (2026-10-28)

- Slack App Home에서 월 1회 다른 팀 동료를 칭찬합니다. 시스템이 본인 추천·조직 조건·월 한도·동일 동료 분기 1회를 검증합니다.
- 관리자 승인·반려·대기 절차 없이 제출 즉시 접수 완료입니다. 과거 승인·반려·대기 기록은 보존하지만 모두 접수로 집계합니다.
- 홈의 발신·수신 건수 모두 해당 분기 전체 접수입니다. 정량은 MIN(100, 수신 접수×5 + 분기 발신 접수 3건 이상 달성5점)입니다.
- 지정 피플팀 관리자만 비공개 접수함과 CSV를 이용합니다. 본인 발신·수신도 조회 가능하며 모든 내역은 조회 전용입니다. 예전 승인·반려 요청은 서버에서 거절합니다.
- 전체 접수의 구체성·핵심가치 부합·도움과 변화는 평가 프롬프트 v2.0으로 정성 채점합니다. 부실한 칭찬도 낮게 채점하여 평균에 포함합니다. 정량·정성은 50:50입니다.
- 공개 채널 게시·수신자 자동 알림은 없습니다. 분기별 선정자 팀의 간식 지원은 별도 운영 절차이며 자동 주문·결제는 없습니다.

## 데이터·권한

직원 명부는 Slack ID와 피플팀 CSV의 상위 조직(part2), 팀/직속 조직(part3), 활성·조직 예외 정보를 DB에 반영합니다. part1은 판정하지 않습니다. 발신자 part3가 있으면 같은 part3 금지, 없으면 같은 part2 금지입니다. 지정 예외도 본인 추천·월/분기 한도는 면제하지 않습니다.

비공개 thankyou 스키마·RLS·service_role 전용 API, Slack HMAC/시각·워크스페이스 검증, OAuth state, 봇 토큰 암호화, 감사 이력을 사용합니다. users:read만 요청하고 메시지 권한은 없습니다. 실제 직원 명부·칭찬 CSV·비밀값은 공개 저장소에 포함하지 않습니다. 최대365일 보존 후 삭제하며 내보낸 파일은 운영자가 별도 관리합니다.

## CSV와 평가

비공개 접수함에서 전체 접수를 CSV로 내보냅니다. 최신순5건씩 조회하며 전체 다운로드는 페이지 크기와 무관합니다. 다운로드 링크는5분·1회용이며 관리자 권한을 다시 확인합니다. CSV는13열(접수번호·접수일시·귀속월·접수상태·작성자/ID/조직·수신자/ID/조직·가치코드/표시명·본문)입니다. 과거 검토자·검토 사유는 현재 내보내기에 포함하지 않습니다.

평가 프롬프트는 docs/evaluation-prompt.ko.md입니다. 귀속월과 접수번호·Slack ID를 기준으로 정량을 검산하고 전체 접수를 1점 단위 정성 평가합니다. 단순한 근거 부족은 낮은 점수이며 평균 분모에서 제외하지 않습니다. AI 평가·최종 순위 저장·수상자 확정은 앱이 자동 수행하지 않습니다. 실제 데이터의 AI 이용은 사내 승인 기준을 따릅니다.

## 배포·검증

신규 설치는 db/schema.sql을 빈 프로젝트에 한 번 실행합니다. 기존 설치에는 db/update-direct-submission.sql과 최신 index.ts를 적용합니다. 이전 마이그레이션을 이후에 재실행하지 않습니다. 월/분기 제한·관리자·보안 설정은 유지됩니다.

운영 함수명과 URL은 기존 thankyou를 유지합니다. Edge Secrets·OAuth·Cron 설정은 EDGE-DEPLOYMENT.md와 supabase/config.toml을 참고합니다. Slack 요청은 사용자 JWT 대신 코드의 Slack 원문 서명으로 검증하므로 legacy JWT 검사 설정을 바꾸기 전 서명 검증을 확인합니다. 공개 앱 화면에 비밀값을 넣지 않습니다.

Node24에서 node --test, node scripts/build-edge.mjs를 실행합니다. db/verify.sql은 자동 접수·모든 상태 집계·발신 보너스·읽기 전용·옛 승인 거절을 검증하고 롤백합니다. db/verify-quarter-recipient.sql은 분기 제한을 검증합니다. verify-legacy-approval.sql은 과거 승인 모델 참고용으로 현재 운영에서 실행하지 않습니다.

현재 분기 Slack 점수 화면은 최대95개 결과이며 과거·전체 분석은 CSV를 사용합니다. 수정·철회·분기 잠금·보상 연동은 별도 범위입니다.
